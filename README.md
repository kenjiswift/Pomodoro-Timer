# ポモドーロタイマー

ブラウザで開くだけで使える、1ファイル完結のポモドーロタイマーです。
インストール不要・外部ライブラリなし・通信なしで動きます。

## 使い方

1. ブラウザで **https://kenjiswift.github.io/Pomodoro-Timer/** を開く(ブックマーク推奨)
2. 「開始」を押すと集中タイマーがスタート
3. 集中が終わると「何を片付けた?」と聞かれるので、一行メモを残す(空欄・スキップも可)
4. 休憩 → 集中 … を繰り返す

画面幅が狭くても崩れないので、ブラウザを細長くして画面の端に置いておく使い方もできます。

## 機能

| 機能 | 内容 |
| --- | --- |
| タイマー | 集中 → 休憩 を自動で切り替え。設定した回数ごとに長い休憩 |
| 操作 | 開始 / 一時停止 / 再開、次へ(今の区間を終えて次へ)、リセット |
| 終了の合図 | 画面中央の大きな案内(OKで閉じる)、画面のふちの光、タブタイトルの点滅。デスクトップ通知をオンにすると、画面右下にメールのような通知が閉じるまで残ります(**音は鳴りません**) |
| タブタイトル | 動作中は残り時間を表示(例:`🍅 12:34 集中`) |
| 今日の記録 | 今日の回数・合計分数と、各回の時刻とメモを一覧表示 |
| 履歴 | 日ごとの記録を表示。日ごと/全部をテキストでコピー、1件削除、全削除 |
| 設定 | テーマ、集中・休憩・長い休憩の分数、長い休憩の間隔(回) |

### テーマ

「設定」→「テーマ」で切り替えられます。選んだテーマは保存され、次回もそのまま開きます。

| テーマ | 見た目 |
| --- | --- |
| ネオン(既定) | 濃紺に細い格子線、光るリングと枠。SFの操作パネル風 |
| オーロラ | ぼかした光の背景に、半透明のガラス風カードとグラデーションのリング |
| コックピット | 真っ黒に一色だけ。リングは60本の目盛りが減っていく計器式 |
| ライト | 明るい背景の、最初のバージョンの見た目 |

どのテーマでも、集中・休憩・長い休憩でアクセント色が変わります。

### 初期設定

- テーマ:ネオン

- 集中:25分
- 休憩:5分
- 長い休憩:15分
- 長い休憩の間隔:4回ごと

## デスクトップ通知

画面右下に出る通知(Windowsの通知)を使うには、最初に許可が必要です。

> **`index.html` をダブルクリックして開いた場合は使えません。** ファイルとして開いたページには、ブラウザ(Edge / Chrome)が通知の許可を記録しないためです。上のサイト版のURLで開いてください。ファイル版とサイト版では履歴が別々に保存されます。

1. タイマー画面の「デスクトップ通知がオフです」の **オンにする** を押す
2. ブラウザに出る確認で「許可」を選ぶ
3. テスト通知が右下に出ればOK(あとから「設定」→「通知テスト」でも確認できます)

通知が出ないときは:

- **ブラウザでブロックしている**:アドレスバー左のアイコン →「通知」を「許可」にして再読み込み
- **Windows側でオフ**:「設定 → システム → 通知」で、使っているブラウザの通知がオンか確認
- **応答不可(集中モード)がオン**:オンの間は通知が右下に出ません
- 会社のPCでは、管理者の設定で通知が使えないこともあります。その場合も画面中央の案内は出ます。

## 補足

- **途中で「次へ」を押した集中は回数に数えません。** 最後まで終えた集中だけが記録されます。
- 設定の変更は、まだ開始していない区間にはすぐ反映され、動作中の区間には次の区間から反映されます。
- タブを閉じたりPCがスリープしたりしても、終了時刻をもとに計算するので時間はずれません。再度開いたときに終了時刻を過ぎていれば、その区間は終了として扱われます。
- コピーされる履歴の形式は次のとおりです。

  ```
  10/23(木) 3回 75分
    09:30 25分 メール返信
    10:00 25分 資料作成
    10:35 25分
  ```

## データの保存先

設定・タイマーの状態・履歴は、ブラウザの `localStorage` に保存されます。

- データはそのPC・そのブラウザの中だけにあり、外部には送信されません。
- 別のブラウザや別のPCとは共有されません。
- ブラウザの閲覧データを削除すると、履歴も消えます。必要な記録は「全部コピー」で控えておいてください。
- `localStorage` が使えない環境でも動きますが、その場合はページを閉じると記録が消えます。

## 動作環境

Chrome / Edge / Firefox など、最近のブラウザで動作します。
